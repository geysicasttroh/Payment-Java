# Payment-Java 💳

Este projeto é uma implementação prática do padrão de projeto comportamental **Strategy** em Java.

## 📌 Sobre o Projeto
O objetivo é demonstrar a aplicação de boas práticas de programação e orientação a objetos para gerenciar múltiplos métodos de pagamento (como Cartão e Pix) de forma flexível e desacoplada.

## 🛠️ Tecnologias Utilizadas
* **Java**
* **Maven**

## 🎯 Padrão Strategy
O padrão Strategy permite definir uma família de algoritmos, encapsular cada um deles e torná-los intercambiáveis, promovendo o princípio do *Open/Closed (SOLID)*.
